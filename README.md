# C++ Projects for CodeAlpha Internship

Collection of 3 C++ Console Projects built for CodeAlpha Internship Application.

## Projects Included:

### 1. Calculator.cpp
A simple console calculator that performs +, -, *, / operations.
Features: Loop to calculate multiple times, Error handling for divide by zero.

### 2. StudentSystem.cpp  
Student Management System to store and display student data.
Features: Store up to 3 students, Pass/Fail result based on marks.

### 3. TicTacToe.cpp
2 Player Tic Tac Toe Game in Console.
Features: Board display, Input validation, Turn switching.

## Technologies Used:
- C++
- Basic OOP Concepts
- Arrays and Loops
- Problem Solving
